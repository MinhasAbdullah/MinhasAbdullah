## Projects

### 🏠 Roshan Aashiyana — Smart Property Marketplace
> *Full-stack real estate platform built for Pakistan · Deployed on Railway*

A platform that replaces Pakistan's offline property search with a centralised, secure digital marketplace —
covering Islamabad, Lahore, Rawalpindi, Karachi, and Multan.

- **AI-powered listing generator** — Mistral AI via LangChain auto-generates professional property descriptions from basic inputs
- **Dual account system** — normal users + verified dealers with email verification via Resend API
- **Stripe payment gateway** — dealer subscription billing, fully integrated
- **Cloudinary** — image upload and storage for all property listings
- **Advanced search & filtering** — city, type, purpose, price range, bedrooms
- **Inquiry system** — automated email notifications to dealers on new inquiries
- **Favourites, reviews & ratings, admin dashboard** with analytics

`Django` `PostgreSQL (Neon)` `Mistral AI` `LangChain` `Stripe` `Cloudinary` `Resend API` `Railway`
