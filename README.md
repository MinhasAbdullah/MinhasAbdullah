## Projects

### 🏠 Roshan Aashiyana — Smart Property Marketplace
> *Full-stack real estate platform built for Pakistan · Live in Production*

A platform replacing Pakistan's offline property search with a secure digital marketplace covering Islamabad, Lahore, Rawalpindi, Karachi, Multan and more.

- **AI description generator** — Mistral AI + LangChain generates 80-120 word professional listings from property inputs in one click
- **Dual account system** — buyers + verified dealers with email verification, forgot password flow, and account settings
- **Stripe payment gateway** — one-time dealer registration billing, fully verified server-side
- **Cloudinary image storage** — direct upload from browser, bypassing server entirely (cut upload time from 20min → instant)
- **Advanced search** — filter by city, type, purpose, price, bedrooms, keyword with live autocomplete
- **Full dealer dashboard** — add/edit/delete listings, inquiry management, analytics (views + inquiries)
- **Branded HTML emails** — verification, welcome, inquiry notifications, password reset via Resend API
- **Favourites, reviews, dealer profiles, legal pages** — production-ready feature set

`Django 6` `Python 3.13` `PostgreSQL (Neon)` `Mistral AI` `LangChain` `Stripe` `Cloudinary` `Resend API` `WhiteNoise` `Railway`

### 🚛 TruckLink — Driver Hiring & Onboarding Portal
> *Team Lead · Zeppelin Labs Web Dev Fellowship*

Role-based hiring platform connecting drivers, recruiters, and admins. Every driver profile is admin-moderated
before it's ever visible to a recruiter — access control enforced at the API layer, not just the UI.

- **JWT auth** with three distinct roles (Driver / Recruiter / Admin)
- **Moderation pipeline** — approve/reject/request-changes workflow with timestamped status history
- **Rule-based matching** — recruiters see only approved drivers filtered against job requirements
- **Document uploads** via Cloudinary, real-time notifications via Django Channels

`Django REST Framework` `React` `PostgreSQL` `JWT` `Django Channels` `Cloudinary`

### 🚗 CarpoolCampus — Ride-Sharing Coordination for Students
> *Team Lead · Zeppelin Labs Web Dev Fellowship*

Carpool-matching platform for commuting students with recurring route scheduling and automated cost-splitting.

- **Campus-email domain verification** (`.edu.pk`) for trusted student-only signups
- **Route-overlap matching engine** for driver/rider route + timing compatibility
- **Distance-based cost-split calculator** — automatic per-rider fare calculation
- Safety features: emergency contact sharing, admin moderation for flagged reports

`Django REST Framework` `React` `PostgreSQL` `JWT` `Django Channels`
